Code

GAMS with Python

The model is written in GAMS. Python handles data preparation and the run scripts. A GAMS licence and solver are your own.

Documents

Documentation and guide

The theoretical documentation and the user guide are in the same repository, in LaTeX source and as published PDFs.

Data

Benchmark data

The Danish benchmark data set was produced by Statistics Denmark and carries its own terms. What is redistributable is stated in the repository.

Licence

To be confirmed before launch. DREAM holds the intellectual property in the model. The licence text for version 2.0 will be stated here and in the repository. Code, documentation and data may sit under different terms.

If you are calibrating a country

The model is a small open economy CGE calibrated to national accounts and energy balances. The industry list is a property of the data set: the Danish benchmark has 57 industries, and other calibrations differ. Start from Chapter 1 of the documentation, then the user guide.

DREAM has supported ministry teams in Austria, Belgium, Finland and Italy through this route. Their work is described under Applications.
